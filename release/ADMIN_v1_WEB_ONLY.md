# YALA Enterprise v1.0 — Admin Portal Distribution Policy

**Effective:** 2026-07-22  
**Decision:** Admin Portal ships as **web-only** for v1.0 closed beta.

| Channel | v1.0 status |
|---------|-------------|
| Web admin (`https://www.yalataxi.live/admin`) | ✅ Supported |
| Android Admin APK/AAB | ❌ Not required for closed beta |

Native Admin wrapper (`admin-app/`) remains in repo for future store release; no signed Admin artifact is required for Sprint 1 closed beta.
