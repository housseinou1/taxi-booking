# Design Document: Mobile App Stores

## Overview

This design wraps the existing Yala React web application into two native mobile apps using [Capacitor](https://capacitorjs.com/) v6. The approach creates two separate Capacitor projects (`rider-app/` and `driver-app/`) that each build the same React frontend with environment-specific configuration to filter routes and apply branding.

The key architectural decision is to keep a **single React codebase** in `frontend/` and use build-time environment variables plus a runtime platform detection utility to control which features are active in each app. This avoids code duplication while producing distinct app binaries.

**Target platforms:**
- iOS 15.0+ (iPhone/iPad)
- Android 7.0+ (API 24)

**Bundle identifiers:**
- Rider: `com.yala.rider`
- Driver: `com.yala.driver`

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                   React Frontend                     │
│              (frontend/src - shared)                 │
├─────────────────────────────────────────────────────┤
│         Platform Abstraction Layer                   │
│   (src/native/platform.js, src/native/storage.js)   │
├──────────────────────┬──────────────────────────────┤
│   rider-app/         │   driver-app/                │
│   (Capacitor proj)   │   (Capacitor proj)           │
│   - capacitor.config │   - capacitor.config         │
│   - ios/             │   - ios/                     │
│   - android/         │   - android/                 │
├──────────────────────┴──────────────────────────────┤
│              Native Plugins (Capacitor)              │
│  Push | Geolocation | Camera | Biometrics | App     │
├─────────────────────────────────────────────────────┤
│              iOS / Android OS                        │
└─────────────────────────────────────────────────────┘
```

**How it works:**
1. `npm run build` in `frontend/` produces a static React build
2. A build script copies the output into the Capacitor project's `www/` directory
3. `npx cap sync` installs native plugins and syncs web assets
4. Xcode / Android Studio (or CLI) produces the final `.ipa` / `.aab`

The React app detects at runtime whether it's inside Capacitor and adjusts behavior (hide PWA button, use secure storage, use hardcoded API URL).

import { Capacitor } from '@capacitor/core';

/**
 * Returns true when running inside a Capacitor native container.
 */
export function isNative() {
  return Capacitor.isNativePlatform();
}

/**
 * Returns 'ios', 'android', or 'web'.
 */
export function getPlatform() {
  return Capacitor.getPlatform();
}

/**
 * Returns 'rider' or 'driver' based on build-time env var.
 */
export function getAppType() {
  return process.env.REACT_APP_TYPE || 'web';
}

/**
 * Returns true if the PWA install button should be shown.

 */

  return !isNative();

### Route Filtering

**In `App.js`, add route filtering based on app type:**
```javascript
import { getAppType } from './native/platform';

const RIDER_ROUTES = [
  '/rider', '/rider-dashboard', '/rider-history', '/rider-reviews',
  '/saved-places', '/rider-profile', '/rider-payments', '/ride/share',
  '/login', '/register', '/settings', '/support', '/terms', '/privacy'
];

const DRIVER_ROUTES = [
  '/driver', '/driver/profile', '/driver/earnings', '/driver/feedback',
  '/driver/support', '/driver/achievements', '/driver/history',
  '/login', '/register', '/settings', '/support', '/terms', '/privacy'
];

function isRouteAllowed(path) {
  const appType = getAppType();
  if (appType === 'web') return true; // No filtering in browser

  const routes = appType === 'rider' ? RIDER_ROUTES : DRIVER_ROUTES;
  return routes.some(route => path === route || path.startsWith(route + '/'));
}

// In the routing logic, redirect to default if route not allowed:
const defaultRoute = getAppType() === 'driver' ? '/driver' : '/rider-dashboard';
```

### Token Storage (Secure Storage)

**frontend/src/native/storage.js:**
```javascript
import { isNative } from './platform';
import { SecureStoragePlugin } from 'capacitor-secure-storage-plugin';

const TOKEN_KEYS = { access: 'jwt_access', refresh: 'jwt_refresh' };

export async function setToken(key, value) {
  if (isNative()) {
    await SecureStoragePlugin.set({ key: TOKEN_KEYS[key], value });
  } else {
    localStorage.setItem(key, value);
  }
}

export async function getToken(key) {
  if (isNative()) {
    try {
      const { value } = await SecureStoragePlugin.get({ key: TOKEN_KEYS[key] });
      return value;
    } catch {
      return null;
    }
  }
  return localStorage.getItem(key);
}

export async function removeToken(key) {
  if (isNative()) {
    try {
      await SecureStoragePlugin.remove({ key: TOKEN_KEYS[key] });
    } catch { /* key may not exist */ }
  } else {
    localStorage.removeItem(key);
  }
}
```

### Push Notification Flow

**frontend/src/native/push.js:**
```javascript
import { isNative } from './platform';
import { PushNotifications } from '@capacitor/push-notifications';
import { API_URL } from '../apiConfig';
import { getToken } from './storage';

export async function initPushNotifications(onNotificationTap) {
  if (!isNative()) return;

  const permission = await PushNotifications.requestPermissions();
  if (permission.receive !== 'granted') return;

  await PushNotifications.register();

  // Token received - send to backend
  PushNotifications.addListener('registration', async (token) => {
    const jwt = await getToken('access');
    await fetch(`${API_URL}/notifications/register-device/`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${jwt}`,
      },
      body: JSON.stringify({
        token: token.value,
        platform: Capacitor.getPlatform(), // 'ios' or 'android'
      }),
    });
  });

  // Notification tapped - navigate to relevant screen
  PushNotifications.addListener('pushNotificationActionPerformed', (notification) => {
    const data = notification.notification.data;
    if (onNotificationTap) {
      onNotificationTap(data);
    }
  });
}

/**
 * Computes the navigation route from a notification payload.
 */
export function getRouteFromNotification(data, appType) {
  if (!data || !data.type) return null;

  if (appType === 'rider') {
    switch (data.type) {
      case 'ride_status': return `/rider-dashboard`;
      case 'ride_complete': return `/rider-history`;
      default: return '/rider-dashboard';
    }
  }

  if (appType === 'driver') {
    switch (data.type) {
      case 'new_ride_request': return `/driver`;
      case 'ride_update': return `/driver`;
      default: return '/driver';
    }
  }

  return null;
}
```

### Background Location (Driver)

**frontend/src/native/location.js:**
```javascript
import { isNative, getPlatform } from './platform';
import { Geolocation } from '@capacitor/geolocation';
import { BackgroundGeolocation } from '@capacitor-community/background-geolocation';

let watchId = null;

export async function requestLocationPermission(background = false) {
  if (!isNative()) return { granted: true }; // Browser handles its own

  const perm = await Geolocation.requestPermissions();
  if (perm.location !== 'granted') {
    return { granted: false, reason: 'foreground_denied' };
  }

  if (background && getPlatform() === 'android') {
    // Android requires separate background permission
    const bgPerm = await Geolocation.requestPermissions({ permissions: ['coarseLocation'] });
    if (bgPerm.location !== 'granted') {
      return { granted: false, reason: 'background_denied' };
    }
  }

  return { granted: true };
}

export async function startBackgroundLocationTracking(wsConnection) {
  if (!isNative()) return;

  await BackgroundGeolocation.addWatcher(
    {
      backgroundMessage: 'Yala Driver is tracking your location',
      backgroundTitle: 'Location Active',
      requestPermissions: true,
      stale: false,
      distanceFilter: 10, // meters
    },
    (location, error) => {
      if (error) return;
      if (wsConnection && wsConnection.readyState === WebSocket.OPEN) {
        wsConnection.send(JSON.stringify({
          type: 'location_update',
          latitude: location.latitude,
          longitude: location.longitude,
          timestamp: new Date().toISOString(),
        }));
      }
    }
  );
}

export async function stopBackgroundLocationTracking() {
  if (watchId) {
    await BackgroundGeolocation.removeWatcher({ id: watchId });
    watchId = null;
  }
}
```

### Deep Link Handling

**frontend/src/native/deeplink.js:**
```javascript
import { App } from '@capacitor/app';
import { getAppType } from './platform';

/**
 * Parses a deep link URL into an internal route path.
 * Handles both custom schemes (yala-rider://, yala-driver://)
 * and universal links (https://yala.mr/rider/*, https://yala.mr/driver/*).
 */
export function parseDeepLink(url) {
  if (!url) return null;

  // Custom scheme: yala-rider://rider-dashboard → /rider-dashboard
  const schemeMatch = url.match(/^yala-(rider|driver):\/\/(.*)$/);
  if (schemeMatch) {
    return '/' + schemeMatch[2].replace(/^\//, '');
  }

  // Universal link: https://yala.mr/rider/dashboard → /rider-dashboard
  const universalMatch = url.match(/^https:\/\/yala\.mr\/(rider|driver)\/(.*)$/);
  if (universalMatch) {
    const type = universalMatch[1];
    const path = universalMatch[2];
    if (type === 'rider') return `/rider-${path}` || '/rider-dashboard';
    if (type === 'driver') return `/driver/${path}` || '/driver';
  }

  return null;
}

export function initDeepLinkListener(navigateFn) {
  App.addListener('appUrlOpen', (event) => {
    const route = parseDeepLink(event.url);
    if (route) {
      navigateFn(route);
    }
  });
}
```

### Biometric Authentication

**frontend/src/native/biometric.js:**
```javascript
import { isNative } from './platform';
import { NativeBiometric } from 'capacitor-native-biometric';

const BACKGROUND_THRESHOLD_MS = 5 * 60 * 1000; // 5 minutes
let lastBackgroundTime = null;

/**
 * Determines if biometric prompt should be shown based on background duration.
 */
export function shouldPromptBiometric(backgroundDurationMs) {
  return backgroundDurationMs > BACKGROUND_THRESHOLD_MS;
}

export async function isBiometricAvailable() {
  if (!isNative()) return false;
  try {
    const result = await NativeBiometric.isAvailable();
    return result.isAvailable;
  } catch {
    return false;
  }
}

export async function performBiometricVerification() {
  return NativeBiometric.verifyIdentity({
    reason: 'Verify your identity to access Yala',
    title: 'Biometric Login',
  });
}

export function recordBackgroundTime() {
  lastBackgroundTime = Date.now();
}

export function getBackgroundDuration() {
  if (!lastBackgroundTime) return 0;
  return Date.now() - lastBackgroundTime;
}
```

### External Navigation

**frontend/src/native/navigation.js:**
```javascript
import { getPlatform } from './platform';

/**
 * Formats coordinates into a URL for the device's maps application.
 * Returns a URL string compatible with Google Maps (Android) or Apple Maps (iOS).
 */
export function formatMapsUrl(lat, lng, label = 'Destination') {
  const platform = getPlatform();

  if (platform === 'android') {
    return `google.navigation:q=${lat},${lng}`;
  }

  // iOS - Apple Maps
  return `maps://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`;
}

/**
 * Opens turn-by-turn navigation to the given coordinates.
 */
export function openNavigation(lat, lng, label) {
  const url = formatMapsUrl(lat, lng, label);
  window.open(url, '_system');
}
```

### WebSocket Reconnection with Exponential Backoff

```javascript
/**
 * Computes the reconnection delay using exponential backoff.
 * Base: 1000ms, multiplier: 2, cap: 30000ms.
 */
export function computeReconnectDelay(attemptNumber) {
  const base = 1000;
  const multiplier = 2;
  const maxDelay = 30000;
  const delay = Math.min(base * Math.pow(multiplier, attemptNumber), maxDelay);
  return delay;
}
```

## Correctness Properties

*A property is a characteristic or behavior that should hold true across all valid executions of a system — essentially, a formal statement about what the system should do. Properties serve as the bridge between human-readable specifications and machine-verifiable correctness guarantees.*

### Property 1: Route filtering correctness

*For any* route path string, the route filter function for a given app type (rider or driver) SHALL return `true` only if the path belongs to that app's allowed route set, and `false` for all routes belonging to the other app type (excluding shared routes like `/login`, `/settings`).

**Validates: Requirements 1.3, 1.4**

### Property 2: Notification payload produces correct navigation route

*For any* valid notification payload containing a `type` field and a `ride_id`, the `getRouteFromNotification` function SHALL return a non-null route string that starts with the correct prefix for the app type (`/rider` for rider app, `/driver` for driver app).

**Validates: Requirements 3.7, 3.8**

### Property 3: Deep link parsing produces valid internal routes

*For any* valid deep link URL (either custom scheme `yala-rider://path` / `yala-driver://path` or universal link `https://yala.mr/rider/path` / `https://yala.mr/driver/path`), the `parseDeepLink` function SHALL return a string starting with `/` that corresponds to a valid internal route.

**Validates: Requirements 6.1, 6.2, 6.3, 6.4**

### Property 4: Image compression respects size bound

*For any* image input (regardless of original size or format), the compression function SHALL produce output that is less than or equal to 2 MB (2,097,152 bytes).

**Validates: Requirements 5.2**

### Property 5: Offline cache stores at most 20 rides

*For any* array of rides fetched from the backend (of any length), the cache storage function SHALL store exactly `min(rides.length, 20)` entries, and those entries SHALL be the most recent by `created_at` timestamp.

**Validates: Requirements 8.1**

### Property 6: Biometric timeout threshold

*For any* non-negative background duration in milliseconds, the `shouldPromptBiometric` function SHALL return `true` if and only if the duration exceeds 300,000 ms (5 minutes).

**Validates: Requirements 9.2, 9.3**

### Property 7: Exponential backoff with cap

*For any* non-negative integer attempt number, the `computeReconnectDelay` function SHALL return a value equal to `min(1000 * 2^attempt, 30000)`, which is always between 1000 and 30000 inclusive.

**Validates: Requirements 12.5**

### Property 8: Token refresh triggers on expiry

*For any* JWT access token that has an expiration time in the past and a valid (non-expired) refresh token, the token management layer SHALL initiate a refresh request without requiring user interaction, and the resulting new access token SHALL have an expiration time in the future.

**Validates: Requirements 13.3, 13.4**

## Error Handling

| Scenario | Behavior |
|----------|----------|
| Location permission denied (rider) | Show inline message: "Location is required to set your pickup point" with link to device settings |
| Background location denied (driver) | Show modal: "Background location is required to receive ride requests while the app is minimized" with settings link |
| Camera permission denied | Show message directing user to Settings → Yala → Camera |
| Push notification permission denied | App functions normally but user misses real-time updates; show banner suggesting to enable |
| Network offline (cached data exists) | Show cached data with "Offline" badge; hide actions that require network |
| Network offline (no cache) | Show full-screen "No internet connection" with retry button |
| WebSocket disconnect | Exponential backoff reconnection (1s, 2s, 4s, 8s, 16s, 30s cap) |
| Biometric fails 3 times | Fall back to username/password login screen |
| Secure storage read fails | Fall back to localStorage (graceful degradation) |
| Refresh token expired | Clear all tokens, redirect to login screen |
| Deep link to unknown route | Navigate to app's default screen (rider-dashboard or driver) |

| Property | Test Description |

| 2: Notification routing | Generate random notification payloads, verify route prefix matches app type |
| 3: Deep link parsing | Generate random valid deep link URLs (both schemes), verify parsed route starts with `/` |
| 4: Image compression | Generate random buffer sizes, verify output ≤ 2MB |
| 5: Cache size invariant | Generate random ride arrays (0-100 items), verify cache stores ≤ 20 most recent |
| 6: Biometric timeout | Generate random durations (0 - 10 minutes), verify threshold logic |
| 7: Backoff cap | Generate attempt numbers (0-100), verify delay formula and 30s cap |
| 8: Token refresh | Generate random expiry timestamps, verify refresh triggers correctly |

**Configuration:**
- Library: `fast-check` v3+
- Iterations: 100 minimum per property
- Tag format: `Feature: mobile-app-stores, Property {N}: {title}`
